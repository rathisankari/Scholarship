# Scholarship Advisor

A Python-based console application that helps students identify suitable scholarship opportunities based on their academic details, personal information, and eligibility criteria.

## Project Overview

Many students are unaware of available scholarships or find it difficult to identify scholarships that match their eligibility. This project provides a simple scholarship recommendation system where students can enter their details and receive suitable scholarship suggestions.

The system compares student information with predefined scholarship criteria and recommends scholarships based on factors such as academic performance, income level, category, and course details.

## Problem Statement

Students often miss scholarship opportunities due to a lack of awareness and difficulty in finding scholarships that match their eligibility requirements. Searching through multiple sources manually is time-consuming and inefficient.

## Proposed Solution

The Scholarship Advisor provides a centralized console-based system that:

- Collects student academic and personal information
- Evaluates eligibility criteria
- Matches students with suitable scholarships
- Displays scholarship details and benefits

## Objectives

- Simplify the scholarship searching process
- Help students discover suitable scholarship opportunities
- Reduce manual effort in finding eligibility information
- Provide an easy-to-use recommendation system

## Features

### Student Profile Management

The system collects and processes student information including:

- Student name
- Academic performance
- Course details
- Category
- Family income
- Other eligibility-related details

### Scholarship Recommendation

The application recommends scholarships by comparing student information with available scholarship criteria.

Recommendation is based on:

- Academic marks or CGPA
- Income eligibility
- Category requirements
- Educational background

### Scholarship Details

Provides information about:

- Scholarship name
- Eligibility criteria
- Benefits
- Application requirements

### Data Management

- Maintains scholarship information
- Processes student details efficiently
- Uses structured data storage for scholarship records
